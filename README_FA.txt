سامانه صدای دانش‌آموز — نسخه سازگار با Vercel

مهم: این نسخه، server.js محلی را کنار می‌گذارد و از توابع API داخل پوشه api استفاده می‌کند. ذخیره‌سازی پایدار با GitHub Contents API انجام می‌شود.

۱) فایل‌های این بسته را در ریشه پروژه‌ای قرار بده که در Vercel Deploy می‌کنی؛ یعنی index.html، style.css، app.js، پوشه‌های api و lib، فایل package.json و فایل vercel.json باید در کنار هم باشند.

۲) برای ذخیره‌سازی، یک مخزن GitHub جداگانه و Private بساز؛ مثلاً student-voice-data و هنگام ساخت آن گزینه Add a README را فعال کن تا شاخه اصلی (main) ایجاد شود. استفاده از مخزن جدا مهم است تا هر پیام جدید باعث Deploy دوباره سایت اصلی نشود. لازم نیست فایل letters.json را از قبل بسازی؛ برنامه آن و فایل‌های پیوست را ایجاد می‌کند.

۳) در GitHub یک Fine-grained personal access token بساز که فقط به مخزن داده دسترسی داشته باشد و در Repository permissions، مجوز Contents را روی Read and write بگذار.

۴) در Vercel وارد Project → Settings → Environment Variables شو و این متغیرها را اضافه کن:

GITHUB_TOKEN = توکن GitHub که ساخته‌ای
GITHUB_OWNER = نام کاربری یا سازمان مالک مخزن داده
GITHUB_REPO = نام مخزن داده، بدون .git
GITHUB_BRANCH = main (اختیاری؛ اگر شاخه اصلی مخزن اسم دیگری دارد، همان نام را بنویس)

توکن را در app.js یا هیچ فایل عمومی قرار نده؛ فقط در Environment Variables مربوط به Vercel تنظیمش کن.

۵) بعد از ذخیره متغیرها، یک Deploy تازه بگیر تا مقادیر جدید فعال شوند.

۶) این دو آدرس را آزمایش کن:
- https://YOUR-SITE.vercel.app/api/health
  باید JSON با ok: true برگرداند.
- https://YOUR-SITE.vercel.app/api/letters
  اگر هنوز پیامی ثبت نشده باشد، باید [] برگرداند. بعد از ارسال پیام باید فهرست پیام‌ها را برگرداند.

اگر /api/health هم 404 می‌دهد، احتمالاً پوشه api را در ریشه پروژه قرار نداده‌ای یا Root Directory در تنظیمات Vercel به پوشه اشتباهی اشاره می‌کند. اگر health در دسترس است اما خطای 503 می‌دهد، متغیرهای GitHub را بررسی کن. اگر خطای 502 می‌بینی، متن پاسخ معمولاً مشکل مخزن، شاخه یا مجوز توکن را مشخص می‌کند.

محدودیت پیوست‌ها در این نسخه:
- حداکثر ۵ فایل برای هر پیام.
- حداکثر ۲٫۵ مگابایت برای هر فایل؛ مجموعاً حداکثر ۱۲٫۵ مگابایت.
- فایل‌ها جداگانه فرستاده می‌شوند تا درخواست‌های Vercel از محدودیت حجم بدنه عبور نکنند.

درباره محل ذخیره‌سازی:
- متن پیام‌ها و اطلاعات پیوست‌ها در data/letters.json مخزن داده ثبت می‌شود.
- خود فایل‌های پیوست در data/attachments/ ذخیره می‌شوند.
- هر پیام یا پیوست جدید یک Commit در مخزن داده ایجاد می‌کند؛ برای همین مخزن داده را از مخزن کد سایت جدا نگه دار.
- پیام‌هایی که قبلاً فقط در IndexedDB مرورگر ذخیره شده بودند، خودکار به مخزن جدید منتقل نمی‌شوند.

پروژه هیچ پکیج npm اضافه‌ای نیاز ندارد. از تنظیمات Vercel، Framework Preset را روی Other بگذار؛ Root Directory باید همان پوشه‌ای باشد که index.html و پوشه api داخل آن هستند. Build Command و Output Directory را خالی بگذار مگر اینکه خود پروژه‌ات تنظیم دیگری لازم داشته باشد.
